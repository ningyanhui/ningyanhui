01｜本周执行摘要

本周真正值得关注的是：Agent 开始进入数据基础设施的控制面、调度面和存储层，而不再只是外部问答应用。

Flink Operator 可编程运维

Autoscaler 扩展点使 Agent 可以参与扩缩容判断，同时继续由 Operator 承担安全执行边界。

Lakehouse 原生 Vector

Paimon Vector Index 持续增强，部分语义检索场景开始有机会减少独立 Vector DB 数据副本。

MCP 进入治理层

企业关注点从“能接多少 Tool”转向身份、权限、审计、限流、成本和可观测性。

多模态 Data Layer

Lance / LanceDB 的价值越来越接近 AI Data Lake，而不只是另一套 Vector Database。

趋势判断： Data Platform → Agent Application 正在演变为 Data Platform ↔ Agent Control Plane。

03｜深度分析

P0 · Flink

Operator 成为 Agent 的安全执行器

让 Agent 输出 root cause、target parallelism、evidence、risk，再由 Policy 与 Operator 决定是否执行。适合 Kafka Lag、Backpressure、Checkpoint 和 TM 资源异常场景。

P0 · Paimon

Lakehouse Native Vector

重点验证 Recall@10、P95/P99、索引构建、增量写入与 Compaction 影响，而不是默认替代专业 Vector DB。

P0 · MCP

Tool 治理成为核心

统一 Identity、Permission、Audit、Timeout、Retry、Idempotency、Cost 与 Trace；Agent 不直接持有数据库和集群高权限。

P1 · Lance

多模态数据需要新的 Data Layer

Image、Audio、Video、PDF、Embedding、Feature、Training Sample、Agent Memory 正形成新的基础设施需求。

P1 · ClickHouse

Agent Serving Database

OLAP、JSON、Text、Vector、Lakehouse Query 与后台长任务逐步汇聚到同一系统，适合作为 Data Agent Serving Layer。

P1 · Agent Ops

规则 + Agent + Evaluator

确定性判断留给 Flink/SQL；复杂根因交给 Agent；高风险动作继续通过 Policy 或人工审批。
